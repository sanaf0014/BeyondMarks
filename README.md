# Beyond Marks

AI-assisted learning intelligence: evaluates student explanations, not just right/wrong answers.

## Stack
React + Vite + Tailwind CSS, Firebase (Auth, Firestore, Hosting, AI Logic SDK), Gemini Flash (free tier).

## Getting started
```bash
npm install
cp .env.example .env.local   # fill in Firebase values later
npm run dev                  # http://localhost:5173
npm run build                # production build
```
